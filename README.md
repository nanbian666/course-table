# 课程表 · 我的第一个 Web 项目

把课程表做成一个能随时打开、自动定位到今天、支持单双周的网页。

**不需要安装任何东西**：双击 `index.html` 就能用。

已经做好的功能：自动定位本周和今天 · 单双周过滤 · 左右方向键切周 · 暗色模式 · 手机可左右滑动 · 可直接打印。

---

## 一、30 秒跑起来

1. 打开文件夹 `course-table`
2. 双击 `index.html`
3. 看到课表 → 成功

页面会自动计算本周是第几周、今天周几，并高亮今天的课。

## 二、怎么改

| 想改什么 | 改哪个文件 |
|---|---|
| 课表内容（课程、时间、地点） | `data/courses.js` |
| 开学日期、总周数、每节课几点 | `data/meta.js` |
| 颜色、字体、圆角、暗色模式 | `css/style.css` 顶部的 `:root` |
| 页面逻辑 | `js/app.js` |

改完保存，刷新浏览器即可。

### 加一门课

打开 `data/courses.js`，在列表里复制一块改改：

```js
{
  name: "数据库原理",
  teacher: "黄老师",
  location: "教二-301",
  day: 3,            // 3 = 周三
  startSection: 7,   // 第 7 节开始
  endSection: 8,     // 第 8 节结束
  weeks: [1, 16],    // 第 1~16 周；不连续就写 [[2,3],[5,9],[11,17]]
  parity: "all"      // all=每周 / odd=单周 / even=双周
}
```

> 注意：最后一块后面**不要**加逗号，否则整页空白。

**周次不连续（2-3 周、5-9 周、11-17 周）就写成数组套数组**：

```js
weeks: [[2, 3], [5, 9], [11, 17]],
```

页面上会显示成「第2–3、5–9、11–17周」，第 4 周和第 10 周自动不排这门课。

## 三、用 Excel 填，自动生成（可选）

不想手写 JS？用 Excel：

```bash
# 1. 生成模板（只需一次）
python tools/make_template.py

# 2. 用 Excel 填好 课程表模板.xlsx

# 3. 转换
python tools/excel_to_js.py --input 课程表模板.xlsx

# 4. 刷新网页
```

这一步需要 Python 环境：

```bash
pip install -r requirements.txt
```

转换脚本会帮你检查：星期填错、节次倒挂、周次不对、两门课撞车——都会指出是第几行。

**【上课周次】这一列怎么写：**

| 写法 | 含义 |
|---|---|
| `1-16` | 第 1 到 16 周，每周都上 |
| `2-3,5-9,11-17` | 第 2-3、5-9、11-17 周（跳过第 4、10 周） |
| `3` | 只上第 3 周 |
| `1,3,5,7` | 只上第 1、3、5、7 周 |

也认「第2-3周」「2～3」「2至3」，中英文逗号都行。

## 四、目录结构

```
course-table/
├── index.html            # 页面骨架
├── css/style.css         # 样式（含暗色模式、手机适配、打印样式）
├── js/app.js             # 渲染逻辑：算周次、画表格、切周
├── data/
│   ├── meta.js           # 学期设置
│   └── courses.js        # 课程数据
├── tools/
│   ├── make_template.py  # 生成 Excel 模板
│   └── excel_to_js.py    # Excel → courses.js
├── requirements.txt
├── TASKS.md              # 接下来可以做什么（任务卡）
└── README.md
```

**为什么数据用 `.js` 而不是 `.json`？**
因为直接双击打开时（`file://` 协议），浏览器不允许 `fetch` 本地 json 文件，会报 CORS 错误。用 `<script>` 加载 `.js` 就没有这个问题——这是新手最常踩的坑之一。

## 五、发布到网上（可选）

三种方式，从简单到正式：

1. **GitHub Pages**：把文件夹传到 GitHub → Settings → Pages → 选 main 分支 → 得到 `https://你的用户名.github.io/course-table/`
2. **Vercel / Netlify**：拖拽文件夹上传，几十秒出链接
3. **校园网 / 自己电脑**：`python -m http.server 8000`，同学在同一局域网就能访问

## 六、常见问题

**页面一片空白？**
按 `F12` 打开控制台看红色报错。最常见是 `courses.js` 里多了个逗号或少了引号。

**课程不显示？**
检查三件事：`day` 是 1~7、`weeks` 覆盖当前周、`parity` 和当前周的单双匹配。

**周次算错了？**
改 `data/meta.js` 里的 `semesterStart`，必须是第 1 周周一的日期。

**手机上字太小？**
表格可以左右滑动；也可以按 `TASKS.md` 里的任务卡做一个「今日课程」卡片视图。
